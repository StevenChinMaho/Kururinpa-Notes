# 2.8 硬體對程序的支援（Supporting Procedures in Computer Hardware）

## 本節涵蓋主題

| 主題 | 說明 |

## 1. 程序呼叫步驟（Procedure Calling）

1. 將參數放入暫存器（place parameters in registers）
2. 把控制權轉移給程序（transfer control）
3. 取得程序所需的儲存空間（acquire storage）
4. 執行程序的工作（perform operations）
5. 將結果放到呼叫者能取得的暫存器（place result）
6. 返回呼叫點（return to place of call）

---

## 2. 暫存器使用慣例（Register Usage）

| 暫存器 | 編號 | 用途 | 跨呼叫保留？ |
|---|---|---|---|
| `$zero` | 0 | 恆為 0 | — |
| `$at` | 1 | 保留給 assembler（pseudo-instructions） | — |
| `$v0`–`$v1` | 2–3 | 回傳值（result values） | 否 |
| `$a0`–`$a3` | 4–7 | 參數（arguments） | 否 |
| `$t0`–`$t7` | 8–15 | 暫存（temporaries） | **否** |
| `$s0`–`$s7` | 16–23 | 保存（saved） | **是** |
| `$t8`–`$t9` | 24–25 | 更多暫存 | 否 |
| `$k0`–`$k1` | 26–27 | 保留給 OS kernel | — |
| `$gp` | 28 | global pointer（靜態資料） | 是 |
| `$sp` | 29 | stack pointer | 是 |
| `$fp` | 30 | frame pointer | 是 |
| `$ra` | 31 | return address | 是 |

### `$t` 與 `$s` 誰負責保存？

| 暫存器 | 負責者 | 規則 |
|---|---|---|
| `$t0`–`$t9` | **Caller（呼叫者）** | callee 可以任意覆寫；caller 若呼叫後還要用，需在呼叫前自己存起來，callee 返回後再還原 |
| `$s0`–`$s7` | **Callee（被呼叫者）** | callee 若要使用，必須先存到 stack，返回前還原 |

> 口訣：**t = temporary，用了就丟；s = saved，誰動誰還原。**

## 3. 程序呼叫指令（Procedure Call Instructions）

| 指令 | 名稱 | 動作 |
|---|---|---|
| `jal ProcedureLabel` | jump and link | ① 將**下一道指令的位址**（PC + 4）存入 `$ra` ② 跳到目標位址 |
| `jr $ra` | jump register | 將 `$ra` 複製到 PC，返回呼叫者；也可用於 computed jumps（如 switch/case） |

### 範例追蹤

```
位址  指令                 位址  指令
 0    ….                  100   f_add: ….
 4    ….                  104   ….
 8    ….                  108   ….
12    jal f_add           112   ….
16    ….                  116   jr $ra
20    ….                  120   ….
```

| 時點 | 動作 | 結果 |
|---|---|---|
| (1) 執行 `jal f_add`（位址 12） | PC 已加 4 為 16 | `$ra` = 16、PC = 100 |
| (2) 執行 `jr $ra`（位址 116） | PC 已加 4 為 120 | PC = `$ra` = 16 |

> `$ra` 存的是 **jal 下一道指令**的位址（16），不是 jal 本身（12）。

## 4. 葉程序範例（Leaf Procedure Example）

**Leaf procedure**：不會再呼叫其他程序。

```c
int leaf_example(int g, int h, int i, int j)
{
    int f;
    f = (g + h) - (i + j);
    return f;
}
// g, h, i, j 在 $a0–$a3；f 在 $s0（所以要先存 $s0）；結果放 $v0
```

```asm
leaf_example:
    addi $sp, $sp, -4      # 堆疊空出 1 個 word
    sw   $s0, 0($sp)       # 保存 $s0（callee 負責）
    add  $t0, $a0, $a1     # $t0 = g + h
    add  $t1, $a2, $a3     # $t1 = i + j
    sub  $s0, $t0, $t1     # f = $t0 - $t1
    add  $v0, $s0, $zero   # 回傳值 = f
    lw   $s0, 0($sp)       # 還原 $s0
    addi $sp, $sp, 4       # 堆疊收回
    jr   $ra               # 返回
```

| 區段 | 指令 |
|---|---|
| Save `$s0` on stack | `addi $sp`、`sw` |
| Procedure body | `add`、`add`、`sub` |
| Result | `add $v0` |
| Restore `$s0` | `lw`、`addi $sp` |
| Return | `jr $ra` |

> Stack 由**高位址往低位址**成長：push 是 `$sp` **減**、pop 是 `$sp` **加**。

## 5. 非葉程序（Non-Leaf Procedures）

會呼叫其他程序的程序。巢狀呼叫時，caller 需把以下內容存到 stack：

1. **自己的 return address**（`jal` 會覆寫 `$ra`）
2. 呼叫後還需要用到的**參數與暫存值**

呼叫結束後再從 stack 還原。

### 範例：遞迴階乘

```c
int fact(int n)
{
    if (n < 1) return 1;
    else return n * fact(n - 1);
}
// n 在 $a0；結果在 $v0
```

```asm
fact:
    addi $sp, $sp, -8      # 堆疊空出 2 個 word
    sw   $ra, 4($sp)       # 保存 return address
    sw   $a0, 0($sp)       # 保存參數 n
    slti $t0, $a0, 1       # $t0 = (n < 1)
    beq  $t0, $zero, L1    # n >= 1 就跳到 L1
    addi $v0, $zero, 1     # n < 1：結果 = 1
    addi $sp, $sp, 8       #   彈出 2 個 word
    jr   $ra               #   返回
L1: addi $a0, $a0, -1      # n = n - 1
    jal  fact              # 遞迴呼叫 fact(n - 1)
    lw   $a0, 0($sp)       # 還原原本的 n
    lw   $ra, 4($sp)       # 還原 return address
    addi $sp, $sp, 8       # 彈出 2 個 word
    mul  $v0, $a0, $v0     # 結果 = n × fact(n - 1)
    jr   $ra               # 返回
```

> base case（n < 1）沒有修改 `$ra`、`$a0`，所以不用 `lw` 還原，直接 pop 即可。

### 追蹤 fact(2)（自製）

呼叫鏈：fact(2) → fact(1) → fact(0)

| 階段 | Stack 內容（由上往下為 push 順序） | `$v0` |
|---|---|---|
| fact(2) 進入 | [ra=呼叫者, n=2] | |
| fact(1) 進入 | [ra=呼叫者, n=2] [ra=fact內, n=1] | |
| fact(0) 進入 | … [ra=fact內, n=0] | |
| fact(0) 返回 | pop 1 組 | 1 |
| fact(1) 返回 | 還原 n=1，pop | 1 × 1 = 1 |
| fact(2) 返回 | 還原 n=2，pop | 2 × 1 = 2 |

## 6. 堆疊上的區域資料（Local Data on the Stack）

- 區域資料由 **callee** 配置（例：C 的 automatic variables）。
- **Procedure frame（activation record）**：某些編譯器用來管理 stack 的單位。

Procedure frame 內容（由高位址往低位址）：

| 內容 |
|---|
| Saved argument registers（if any） |
| Saved return address |
| Saved saved registers（if any） |
| Local arrays and structures（if any） |

| 指標 | 指向 |
|---|---|
| `$fp` | frame 的起點（呼叫期間固定） |
| `$sp` | stack 頂端（會隨 push/pop 變動） |

---

## 7. 記憶體配置（Memory Layout）

| 區段（由高到低） | 內容 | 起始位址 / 指標 |
|---|---|---|
| **Stack** | 自動配置（automatic storage），往下長 | `$sp` → `0x7fff fffc` |
| ↕ 空間 | | |
| **Dynamic data（Heap）** | `malloc`（C）、`new`（Java），往上長 | |
| **Static data** | 全域變數、C 的 static 變數、常數陣列與字串 | `$gp` → `0x1000 8000`（區段從 `0x1000 0000` 起）|
| **Text** | 程式碼 | PC → `0x0040 0000` |
| Reserved | 保留 | 0 |

> `$gp` 設在 static data 區段中間，用 ±offset（16-bit）即可存取整個區段。
> Stack 往下長、Heap 往上長，兩者共用中間空間。

---

## 重點整理

| 指令 / 概念 | 功能 | 關鍵注意事項 |
|---|---|---|
| `jal L` | `$ra` = PC + 4；跳到 L | 會覆寫 `$ra` |
| `jr $ra` | PC = `$ra` | 也可用於 switch |
| `$a0`–`$a3` / `$v0`–`$v1` | 參數 / 回傳值 | |
| `$t` 暫存器 | caller-saved | callee 可任意覆寫 |
| `$s` 暫存器 | callee-saved | callee 使用前要存、返回前要還原 |
| Leaf | 不呼叫他人 | 只需保存用到的 `$s` |
| Non-leaf | 呼叫他人 | 必須保存 `$ra` 與之後要用的 `$a`、`$t` |
| Push / Pop | `addi $sp, $sp, -4k` / `+4k` | stack 往低位址長 |
| Memory layout | Stack / Heap / Static / Text | `$sp`、`$gp`、PC 分別指向 |
