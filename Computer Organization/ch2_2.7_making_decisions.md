# 2.7 做決策的指令（Instructions for Making Decisions）

## 1. 條件運算（Conditional Operations）

條件成立時跳到標籤指令，否則**依序執行**下一道。

| 指令 | 意義 |
|---|---|
| `beq rs, rt, L1` | if (rs == rt) 跳到 L1 |
| `bne rs, rt, L1` | if (rs != rt) 跳到 L1 |
| `j L1` | 無條件跳到 L1 |

---

## 2. 編譯 if 敘述（Compiling If Statements）

```c
if (i == j) f = g + h;
else        f = g - h;
// f, g, h, i, j 依序在 $s0–$s4
```

```asm
      bne $s3, $s4, Else    # i != j 就跳去 Else（條件反轉）
      add $s0, $s1, $s2     # f = g + h（then 區塊）
      j   Exit              # 跳過 else 區塊
Else: sub $s0, $s1, $s2     # f = g - h
Exit: …
```

> 技巧：C 寫 `i == j`，組語用 **`bne`**——條件**不成立**時跳走，成立就直接往下執行 then 區塊。
> 標籤位址由 **assembler 計算**。

---

## 3. 編譯迴圈（Compiling Loop Statements）

```c
while (save[i] == k) i += 1;
// i 在 $s3、k 在 $s5、save 的 base address 在 $s6
```

```asm
Loop: sll  $t1, $s3, 2      # $t1 = i × 4
      add  $t1, $t1, $s6    # $t1 = &save[i]
      lw   $t0, 0($t1)      # $t0 = save[i]
      bne  $t0, $s5, Exit   # save[i] != k 就離開
      addi $s3, $s3, 1      # i += 1
      j    Loop             # 回到迴圈開頭
Exit: …
```

> 陣列存取三步驟：**index × 4 → 加 base → lw**。

---

## 4. 基本區塊（Basic Blocks）

**Basic block**：一段指令序列，滿足：

1. 中間**沒有分支指令**（除了最後一道）
2. 中間**沒有分支目標**（除了第一道）

> 即「只能從頭進、從尾出」。
> - 編譯器會找出 basic block 做最佳化
> - 進階處理器可以加速 basic block 的執行

---

## 5. 更多條件運算：slt

條件成立時結果設為 1，否則設為 0。

| 指令 | 意義 |
|---|---|
| `slt rd, rs, rt` | if (rs < rt) rd = 1; else rd = 0 |
| `slti rt, rs, constant` | if (rs < constant) rt = 1; else rt = 0 |

搭配 `beq`、`bne` 使用：

```asm
slt $t0, $s1, $s2       # $t0 = ($s1 < $s2) ? 1 : 0
bne $t0, $zero, L       # $t0 != 0 代表 $s1 < $s2 → 跳到 L
```

> 兩道指令合成了 **blt**（branch if less than）。

### 用 slt 組出其他比較

| 想要 | 寫法 |
|---|---|
| if (a < b) goto L | `slt $t0, a, b` ＋ `bne $t0, $zero, L` |
| if (a >= b) goto L | `slt $t0, a, b` ＋ `beq $t0, $zero, L` |
| if (a > b) goto L | `slt $t0, b, a` ＋ `bne $t0, $zero, L` |
| if (a <= b) goto L | `slt $t0, b, a` ＋ `beq $t0, $zero, L` |

## 6. 分支指令的設計（Branch Instruction Design）

**為什麼沒有 `blt`、`bge` 等指令？**

| 理由 | 說明 |
|---|---|
| 硬體速度 | <、≥ 等比較的硬體比 =、≠ **慢** |
| 拖慢時脈 | 比較與分支合在一道指令，每道指令工作量變大 → 時脈變慢 → **所有指令都受影響** |
| Common case | `beq`、`bne` 才是常見情況 |

> 這是**好的設計折衷**（Design Principle 4）。

---

## 7. 有號 vs. 無號比較（Signed vs. Unsigned）

| 類型 | 指令 |
|---|---|
| 有號比較 | `slt`, `slti` |
| 無號比較 | `sltu`, `sltiu` |

> 投影片寫作 `sltui`，正確名稱是 **`sltiu`**（set on less than immediate unsigned）。

**範例**：

```
$s0 = 1111 1111 1111 1111 1111 1111 1111 1111
$s1 = 0000 0000 0000 0000 0000 0000 0000 0001
```

```asm
slt  $t0, $s0, $s1   # 有號：−1 < +1 → $t0 = 1
sltu $t0, $s0, $s1   # 無號：+4,294,967,295 > +1 → $t0 = 0
```

> 同一組位元，解讀方式不同，比較結果就不同。

---

## 重點整理

| 指令 | 功能 | 注意事項 |
|---|---|---|
| `beq` | 相等則分支 | I-format |
| `bne` | 不等則分支 | if 敘述常用（條件反轉） |
| `j` | 無條件跳躍 | J-format（見 2.10） |
| `slt` / `slti` | 有號小於則設 1 | 搭配 `beq`/`bne` 組成 blt、bge 等 |
| `sltu` / `sltiu` | 無號小於則設 1 | 全 1 在無號下是最大值 |
| Basic block | 單一入口、單一出口 | 編譯器最佳化單位 |
| 無 `blt` | 避免拖慢所有指令 | Good design demands good compromises |
