# 2.4 有號數與無號數（Signed and Unsigned Numbers）

> Computer Organization and Design: The Hardware/Software Interface (6th Edition) — Chapter 2

---

## 本節涵蓋主題

| 主題 | 說明 |
|---|---|
| Unsigned binary integers | 範圍 0 ~ 2ⁿ − 1 |
| LSB / MSB | 最右位元 / 最左位元 |
| 2's-complement | 有號整數表示法，範圍 −2ⁿ⁻¹ ~ 2ⁿ⁻¹ − 1 |
| Signed negation | 取補數再加 1 |
| Sign extension | 位元數擴充時複製 sign bit |

---

## 1. 無號二進位整數（Unsigned Binary Integers）

n-bit 數字的值：

$$
x = x_{n-1}2^{n-1} + x_{n-2}2^{n-2} + \cdots + x_1 2^1 + x_0 2^0
$$

- 範圍：**0 ~ +2ⁿ − 1**
- 32 bits：**0 ~ +4,294,967,295**

**範例**：

```
0000 0000 0000 0000 0000 0000 0000 1011₂
= 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11₁₀
```

### LSB 與 MSB

| 名詞 | 位置 |
|---|---|
| **LSB**（least significant bit） | 最右邊，bit 0 |
| **MSB**（most significant bit） | 最左邊，bit 31 |

---

## 2. 二補數有號整數（2's-Complement Signed Integers）

n-bit 數字的值（**最高位權重為負**）：

$$
x = -x_{n-1}2^{n-1} + x_{n-2}2^{n-2} + \cdots + x_1 2^1 + x_0 2^0
$$

- 範圍：**−2ⁿ⁻¹ ~ +2ⁿ⁻¹ − 1**
- 32 bits：**−2,147,483,648 ~ +2,147,483,647**

**範例**：

```
1111 1111 1111 1111 1111 1111 1111 1100₂
= −1×2³¹ + 1×2³⁰ + … + 1×2² + 0×2¹ + 0×2⁰
= −2,147,483,648 + 2,147,483,644 = −4₁₀
```

### 4-bit 對照表

| 二補數 | 十進位 | 二補數 | 十進位 |
|---|---|---|---|
| 0111 | 7 | 1111 | −1 |
| 0110 | 6 | 1110 | −2 |
| 0101 | 5 | 1101 | −3 |
| 0100 | 4 | 1100 | −4 |
| 0011 | 3 | 1011 | −5 |
| 0010 | 2 | 1010 | −6 |
| 0001 | 1 | 1001 | −7 |
| 0000 | 0 | 1000 | **−8** |

### 重要性質

| 性質 | 說明 |
|---|---|
| Bit 31 是 sign bit | 1 = 負數；0 = 非負數 |
| 不對稱 | **−(−2ⁿ⁻¹) 無法表示**（4-bit 有 −8 但沒有 +8） |
| 非負數 | 無號與二補數表示法**相同** |

| 特定值（32-bit） | 位元 |
|---|---|
| 0 | `0000 0000 … 0000` |
| −1 | `1111 1111 … 1111` |
| Most-negative | `1000 0000 … 0000`（−2,147,483,648） |
| Most-positive | `0111 1111 … 1111`（+2,147,483,647） |

---

## 3. 有號數取負（Signed Negation）

> **取補數（complement）再加 1**。Complement：1 → 0、0 → 1。

推導：

$$
x + \bar{x} = 1111\ldots111_2 = -1 \;\Rightarrow\; \bar{x} + 1 = -x
$$

**範例**：對 +2 取負

```
+2 = 0000 0000 … 0010₂
     1111 1111 … 1101₂   ← 取補數
   +                 1
–2 = 1111 1111 … 1110₂
```

---

## 4. 符號擴充（Sign Extension）

用**更多位元**表示同一數字，且**保持數值不變**。

> 方法：**把 sign bit 往左複製**。（無號數則補 0 → zero extension）

**範例**：8-bit → 16-bit

| 數值 | 8-bit | 16-bit |
|---|---|---|
| +2 | `0000 0010` | `0000 0000 0000 0010` |
| −2 | `1111 1110` | `1111 1111 1111 1110` |

### MIPS 中用到 sign extension 的地方

> 投影片在這裡先提到幾個**後面章節才正式介紹**的指令，下表附上一句話說明，細節見對應章節。

| 指令 | 指令意義 | 被擴充的對象 | 詳見 |
|---|---|---|---|
| `addi` | 暫存器加上一個常數，如 `addi $s3, $s3, 4` | 指令中的 16-bit 常數 → 32 bits，才能和 32-bit 暫存器相加 | 2.3 |
| `lb`、`lh` | 從記憶體讀 1 byte（load byte）/ 2 bytes（load halfword）到暫存器 | 讀進來的 8 / 16 bits → 填滿 32-bit 暫存器 | 2.9 |
| `beq`、`bne` | 兩個暫存器相等（branch if equal）/ 不相等（branch if not equal）時，跳到另一道指令 | 指令中「要跳多遠」的 16-bit 位移量（可正可負，往前或往後跳） | 2.7、2.10 |

> 共通點：這些指令都把一個 **16-bit 或更短的有號數**放進 32-bit 的運算中，所以要做 sign extension 才能保持數值（特別是負數）正確。
>
> 對照：`lbu`、`lhu`（unsigned 版本）用 **zero extension**（見 2.9）。

## 練習（自製）

1. 8-bit 二補數 `1011 0101` 的十進位值？
   −128 + 32 + 16 + 4 + 1 = **−75**
2. 求 −75 的相反數（+75）：
   取補數 `0100 1010`，加 1 → `0100 1011` = 64 + 8 + 2 + 1 = **75** ✔
3. 將 `1011 0101` 擴充為 16-bit：
   `1111 1111 1011 0101`（sign bit = 1，左邊補 1）

## 重點整理

| 概念 | 公式 / 方法 | 注意事項 |
|---|---|---|
| Unsigned 範圍 | 0 ~ 2ⁿ − 1 | 32-bit：0 ~ 4,294,967,295 |
| 2's-complement 範圍 | −2ⁿ⁻¹ ~ 2ⁿ⁻¹ − 1 | 負數多一個 |
| 2's-complement 值 | 最高位權重 −2ⁿ⁻¹ | bit 31 = sign bit |
| 取負 | 取補數 + 1 | most-negative 取負會溢位 |
| Sign extension | 複製 sign bit | `addi`、`lb`、`lh`、`beq`、`bne` |
| Zero extension | 補 0 | 無號數、`lbu`、`lhu` |
