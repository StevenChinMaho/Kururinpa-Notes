# 2.3 硬體的運算元（Operands of the Computer Hardware）

## 本節涵蓋主題

| 主題 | 說明 |
|---|---|

## 1. 暫存器運算元（Register Operands）

- 算術指令只能使用**暫存器**當運算元。
- MIPS 有 **32 × 32-bit 的 register file**：
  - 存放經常存取的資料
  - 編號 0–31
  - 32-bit 資料稱為一個 **word**

### 暫存器命名慣例

| 名稱 | 編號 | 用途 |
|---|---|---|
| `$zero` | 0 | 常數 0 |
| `$v0`–`$v1` | 2–3 | 回傳值、運算式求值 |
| `$a0`–`$a3` | 4–7 | 函式參數（arguments） |
| `$t0`–`$t7` | 8–15 | 暫存值（temporaries） |
| `$s0`–`$s7` | 16–23 | 保存變數（saved） |
| `$t8`–`$t9` | 24–25 | 更多暫存值 |
| `$gp` | 28 | global pointer |
| `$sp` | 29 | stack pointer |
| `$fp` | 30 | frame pointer |
| `$ra` | 31 | return address |

> 完整表（含 `$at`=1、`$k0`–`$k1`=26–27）見 2.8 節。

> **Design Principle 2：Smaller is faster（越小越快）**
> 暫存器只有 32 個；主記憶體有數百萬個位置，存取慢得多。

### 範例

```c
f = (g + h) - (i + j);   // f, g, h, i, j 依序在 $s0–$s4
```

```asm
add $t0, $s1, $s2     # $t0 = g + h
add $t1, $s3, $s4     # $t1 = i + j
sub $s0, $t0, $t1     # f = $t0 - $t1
```

## 2. 記憶體運算元（Memory Operands）

- 主記憶體用於**複合資料**：陣列、結構、動態資料。
- 要做運算，必須：
  1. **Load**：把值從記憶體載入暫存器
  2. 運算
  3. **Store**：把結果從暫存器存回記憶體

### 記憶體規則

| 規則 | 說明 |
|---|---|
| Byte addressed | 每個位址對應一個 8-bit byte |
| Word aligned | word 的位址必須是 **4 的倍數** |
| MIPS 是 Big Endian | word 的最高位 byte 放在最低位址 |

### word 編號 vs. byte 位址

| 第幾個 word | byte 位址 |
|---|---|
| 0 | 0 |
| 1 | 4 |
| 2 | 8 |
| 3 | 12 |

> 陣列索引 i 的 byte offset = **i × 4**（int 為 4 bytes）。

---

## 3. Big Endian vs. Little Endian

以數值 `0x12345678` 為例，存放在位址 0–3：

| 位址 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **Big Endian**（MIPS） | 12 | 34 | 56 | 78 |
| **Little Endian**（IA-32、RISC-V） | 78 | 56 | 34 | 12 |

| | 低位址存放 | 口訣 |
|---|---|---|
| Big Endian | 最高位 byte（the leftmost byte） | 大的放前面，像人寫數字 |
| Little Endian | 最低位 byte（the rightmost byte） | 小的放前面 |

> 判斷問題：「**低位址的 byte 存放的是數值中的哪一個 byte？**」

---

## 4. 記憶體運算元範例

### 範例 1：`g = h + A[8]`

g 在 `$s1`、h 在 `$s2`、A 的 base address 在 `$s3`。

```asm
lw  $t0, 32($s3)      # $t0 = A[8]，offset = 8 × 4 = 32
add $s1, $s2, $t0     # g = h + A[8]
```

`lw $t0, 32($s3)` 中：`32` 是 **offset**，`$s3` 是 **base register**。

### 範例 2：`A[12] = h + A[8]`

```asm
lw  $t0, 32($s3)      # $t0 = A[8]
add $t0, $s2, $t0     # $t0 = h + A[8]
sw  $t0, 48($s3)      # A[12] = $t0，offset = 12 × 4 = 48
```

> 常見錯誤：offset 寫成 8 或 12。MIPS 是 byte addressing，**索引要乘 4**。

---

## 5. 暫存器 vs. 記憶體（Registers vs. Memory）

| | Register | Memory |
|---|---|---|
| 存取速度 | 快 | 慢 |
| 運算方式 | 可直接運算 | 需先 load / 後 store → 更多指令 |

- 編譯器必須**盡可能把變數放在暫存器**。
- 只有較少使用的變數才 **spill（溢出）**到記憶體。
- **Register optimization 很重要！**

---

## 6. 立即值運算元（Immediate Operands）

常數直接寫在指令中：

```asm
addi $s3, $s3, 4      # $s3 = $s3 + 4
addi $s2, $s1, -1     # $s2 = $s1 - 1（沒有 subi，用負常數）
```

- MIPS **沒有** subtract immediate 指令 → 用負的常數。

> **Design Principle 3：Make the common case fast（讓常見情況變快）**
> - 小常數非常常見
> - 立即值運算元省掉一道 load 指令

---

## 7. 常數零（The Constant Zero）

- `$zero`（暫存器 0）恆為常數 0，**不能被覆寫**。
- 用於常見操作，例如暫存器間搬移：

```asm
add $t2, $s1, $zero   # $t2 = $s1（相當於 move $t2, $s1）
```

---

## 重點整理

| 指令 / 概念 | 功能 | 注意事項 |
|---|---|---|
| Register file | 32 × 32-bit | Design Principle 2：Smaller is faster |
| `lw rt, off(rs)` | rt = Mem[rs + off] | off 以 byte 計 |
| `sw rt, off(rs)` | Mem[rs + off] = rt | 注意方向：來源在左 |
| Alignment | word 位址為 4 的倍數 | |
| Big Endian | 高位 byte 在低位址 | MIPS；x86、RISC-V 是 Little |
| Spill | 少用變數放記憶體 | 暫存器最佳化很重要 |
| `addi` | 加立即值 | 無 `subi`，用負數；Principle 3 |
| `$zero` | 恆為 0 | 可用來做 move |

> 三個 Design Principle 至此：①Simplicity favors regularity ②Smaller is faster ③Make the common case fast（第④個見 2.5）
