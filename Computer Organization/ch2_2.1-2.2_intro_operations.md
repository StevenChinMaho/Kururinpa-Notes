## 1. 指令集（Instruction Set）

- **Instruction set**：一台電腦所能執行的指令全集（the repertoire of instructions）。
- 不同電腦有不同指令集，但**有許多共同之處**。
- 早期電腦的指令集很簡單 → 實作簡單；許多現代電腦也採用簡單的指令集（RISC）。

### 什麼樣的語言是好的？

> 讓**硬體與編譯器容易建造**，同時**最大化效能、最小化成本與功耗**。

## 3. 算術運算（Arithmetic Operations）

- `add`、`sub` 都有**三個運算元**：兩個來源（source）、一個目的地（destination）。
- **所有**算術運算都採用這個格式。

```asm
add a, b, c     # a = b + c
sub a, b, c     # a = b - c
```

> **Design Principle 1：Simplicity favors regularity（簡單來自規則性）**
> - 規則性讓實作更簡單
> - 簡單能以更低成本達到更高效能

### 範例：編譯運算式

```c
f = (g + h) - (i + j);
```

```asm
add t0, g, h      # 暫存 t0 = g + h
add t1, i, j      # 暫存 t1 = i + j
sub f, t0, t1     # f = t0 - t1
```

> 一行 C 需要多道指令，因為每道指令只能做**一個**運算；編譯器需要產生暫存變數（t0、t1）。
> 實際的 MIPS 運算元必須是暫存器，見 2.3 節。
