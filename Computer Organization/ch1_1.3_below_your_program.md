## 1. 軟硬體分層

硬體只能執行**極為簡單的低階指令**。從複雜的應用程式到這些簡單指令，中間牽涉多層軟體，負責**直譯（interpret）**或**翻譯（translate）**。

```
┌─────────────────────────────┐
│     Application software     │  以高階語言撰寫
│  ┌───────────────────────┐  │
│  │    System software     │  │  Compiler、OS
│  │  ┌─────────────────┐  │  │
│  │  │    Hardware      │  │  │  Processor、Memory、I/O controllers
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| 層級 | 內容 |
|---|---|
| Application software | 以高階語言（HLL）撰寫的應用程式 |
| System software | **Compiler**：將 HLL 翻譯成 machine code<br>**Operating System**：提供服務程式碼（service code） |
| Hardware | Processor、memory、I/O controllers |

### Operating System 的三大工作

1. 處理輸入／輸出（handling I/O）
2. 管理記憶體與儲存空間（managing memory and storage）
3. 排程工作與分享資源（scheduling tasks & sharing resources）

## 2. 專有名詞（Terms）

| 名詞 | 定義 |
|---|---|
| **Compiler（編譯器）** | 將**高階語言**敘述翻譯成**組合語言**敘述的程式 |
| **Instruction（指令）** | 硬體能理解並遵從的命令（command） |
| **Assembler（組譯器）** | 將**符號版本**的指令翻譯成**二進位版本**的程式 |
| **Assembly language（組合語言）** | 機器指令的**符號表示法**（symbolic representation） |
| **Machine language（機器語言）** | 機器指令的**二進位表示法**（binary representation） |

> 易混淆：Compiler 輸出的是**組合語言**（本書定義），Assembler 再轉成**機器語言**。

- 計算機硬體的「字母」只有兩個：0 和 1，稱為二進位數字（binary digit）或**位元（bit）**。
- 組譯器範例（投影片示意）：

```asm
add A, B    ; 符號形式
            ; → 1000110010100000（二進位形式）
```

## 3. 程式碼的層級（Levels of Program Code）

| 層級 | 特性 |
|---|---|
| High-level language | 抽象程度接近問題領域（problem domain）；提供**生產力（productivity）**與**可攜性（portability）** |
| Assembly language | 指令的文字表示（textual representation） |
| Machine language | 硬體表示：二進位位元；**指令與資料都經過編碼（encoded）** |

### 範例：C 的 `swap` 經過編譯與組譯（MIPS）

```c
swap(int v[], int k)
{   int temp;
    temp = v[k];
    v[k] = v[k+1];
    v[k+1] = temp;
}
```

↓ **Compiler**

```asm
swap:
    muli $2, $5, 4      ; $2 = k * 4（每個 int 4 bytes）
    add  $2, $4, $2     ; $2 = v 的位址 + k*4 → &v[k]
    lw   $15, 0($2)     ; $15 = v[k]
    lw   $16, 4($2)     ; $16 = v[k+1]
    sw   $16, 0($2)     ; v[k]   = $16
    sw   $15, 4($2)     ; v[k+1] = $15
    jr   $31            ; 返回呼叫者
```

↓ **Assembler**

```
00000000101000010000000000011000
00000000000110000001100000100001
10001100011000100000000000000000
...（每道指令 32 bits）
```

> 觀察：一行 C 對應多道組合語言指令，而每道組合語言指令大致對應一道機器指令。

## 4. 硬體的基本功能

所有計算機硬體都執行以下四種基本功能：

1. 輸入資料（input）
2. 輸出資料（output）
3. 處理資料（process）
4. 儲存資料（store）

---

## 重點整理

| 概念 | 輸入 → 輸出 |
|---|---|
| Compiler | 高階語言 → 組合語言 |
| Assembler | 組合語言（符號）→ 機器語言（二進位） |
| OS | 管理 I/O、記憶體、排程與資源 |
| HLL 優點 | productivity、portability |
| Machine language | 指令與資料皆以二進位編碼 |
