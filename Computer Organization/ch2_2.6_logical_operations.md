## 1. 邏輯運算總覽

位元層級（bitwise）操作，用於**擷取與插入 word 中的一組位元**。

| 運算 | C | Java | MIPS |
|---|---|---|---|
| Shift left | `<<` | `<<` | `sll` |
| Shift right | `>>` | `>>`（`>>>`） | `srl` |
| Bitwise AND | `&` | `&` | `and`, `andi` |
| Bitwise OR | `\|` | `\|` | `or`, `ori` |
| Bitwise NOT | `~` | `~` | `nor` |

---

## 2. 移位運算（Shift Operations）

使用 R-format，**shamt 欄位**表示移幾位：

| op | rs | rt | rd | shamt | funct |
|---|---|---|---|---|---|
| 6 bits | 5 bits | 5 bits | 5 bits | 5 bits | 6 bits |

| 指令 | 動作 | 數學意義 |
|---|---|---|
| `sll` Shift left logical | 左移，右側補 0 | 左移 i 位 = **乘以 2ⁱ** |
| `srl` Shift right logical | 右移，左側補 0 | 右移 i 位 = **除以 2ⁱ（僅限無號數）** |

```asm
sll $t2, $s0, 4      # $t2 = $s0 << 4（= $s0 × 16）
sll $t1, $s3, 2      # $t1 = i × 4，常用於計算陣列 byte offset
```

> `srl` 左邊補 0，對負數（sign bit = 1）會變成大正數，所以只對無號數等於除法。

---

## 3. AND 運算

**遮罩（mask）**：選取某些位元，其餘清為 0。

```asm
and $t0, $t1, $t2
```

```
$t2 = 0000 0000 0000 0000 0000 1101 1100 0000
$t1 = 0000 0000 0000 0000 0011 1100 0000 0000
$t0 = 0000 0000 0000 0000 0000 1100 0000 0000   ← 兩者皆 1 才為 1
```

---

## 4. OR 運算

**設定某些位元為 1**，其餘不變。

```asm
or $t0, $t1, $t2
```

```
$t2 = 0000 0000 0000 0000 0000 1101 1100 0000
$t1 = 0000 0000 0000 0000 0011 1100 0000 0000
$t0 = 0000 0000 0000 0000 0011 1101 1100 0000   ← 任一為 1 即為 1
```

---

## 5. NOT 運算

**反轉位元**：0 → 1、1 → 0。

MIPS 沒有 NOT 指令，改用三運算元的 **NOR**（維持 R-format 的規則性）：

$$
a \text{ NOR } b = \text{NOT}(a \text{ OR } b)
$$

```asm
nor $t0, $t1, $zero    # $t0 = NOT($t1 OR 0) = NOT $t1
```

```
$t1 = 0000 0000 0000 0000 0011 1100 0000 0000
$t0 = 1111 1111 1111 1111 1100 0011 1111 1111
```

> 技巧：與 `$zero` 做 NOR 就是 NOT（暫存器 0 讀出來永遠是 0）。

---

## 重點整理

| 指令 | 功能 | 常見用途 / 注意事項 |
|---|---|---|
| `sll rd, rt, shamt` | 左移補 0 | 乘以 2ⁱ；陣列 index × 4 |
| `srl rd, rt, shamt` | 右移補 0 | 除以 2ⁱ，**僅無號數** |
| `and` / `andi` | 位元 AND | 遮罩：保留選定位元 |
| `or` / `ori` | 位元 OR | 設定選定位元為 1 |
| `nor` | 位元 NOR | `nor rd, rs, $zero` = NOT |
