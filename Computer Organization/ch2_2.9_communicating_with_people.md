## 1. 字元資料（Character Data）

| 字元集 | 大小 | 內容 |
|---|---|---|
| **ASCII** | 128 個字元（7 bits，以 1 byte 存） | 95 個可顯示字元 + 33 個控制字元 |
| **Latin-1** | 256 個字元（8 bits） | ASCII + 96 個額外可顯示字元 |
| **Unicode** | 32-bit 字元集 | 涵蓋世界上大多數文字與符號；用於 Java、C++ wide characters |
| UTF-8、UTF-16 | 可變長度編碼 | Unicode 的編碼方式 |

## 2. Byte / Halfword 運算

- 可以用位元運算（2.6）處理，但**字串處理是常見情況**（common case），所以 MIPS 提供專用指令。

| 指令 | 動作 | 擴充方式 |
|---|---|---|
| `lb rt, offset(rs)` | 載入 1 byte | **Sign extend** 到 32 bits |
| `lh rt, offset(rs)` | 載入 halfword（2 bytes） | **Sign extend** 到 32 bits |
| `lbu rt, offset(rs)` | 載入 1 byte（unsigned） | **Zero extend** 到 32 bits |
| `lhu rt, offset(rs)` | 載入 halfword（unsigned） | **Zero extend** 到 32 bits |
| `sb rt, offset(rs)` | 存入 rt 最右邊的 1 byte | — |
| `sh rt, offset(rs)` | 存入 rt 最右邊的 halfword | — |

### lb vs. lbu 範例（自製）

記憶體中某 byte 為 `0xF0`（1111 0000）：

```asm
lb  $t0, 0($s0)    # $t0 = 0xFFFFFFF0（sign extend，值為 −16）
lbu $t1, 0($s0)    # $t1 = 0x000000F0（zero extend，值為 240）
```

> 字元處理通常用 **`lbu`**——字元碼沒有負數。

## 3. 字串複製範例（String Copy Example）

C 字串以 **null（`'\0'`，值為 0）結尾**。

```c
void strcpy(char x[], char y[])
{
    int i;
    i = 0;
    while ((x[i] = y[i]) != '\0')
        i += 1;
}
// x、y 的位址在 $a0、$a1；i 在 $s0
```

```asm
strcpy:
    addi $sp, $sp, -4       # 堆疊空出 1 個 word
    sw   $s0, 0($sp)        # 保存 $s0
    add  $s0, $zero, $zero  # i = 0
L1: add  $t1, $s0, $a1      # $t1 = &y[i]
    lbu  $t2, 0($t1)        # $t2 = y[i]
    add  $t3, $s0, $a0      # $t3 = &x[i]
    sb   $t2, 0($t3)        # x[i] = y[i]
    beq  $t2, $zero, L2     # y[i] == 0 就結束迴圈
    addi $s0, $s0, 1        # i = i + 1
    j    L1                 # 下一輪
L2: lw   $s0, 0($sp)        # 還原 $s0
    addi $sp, $sp, 4        # 彈出
    jr   $ra                # 返回
```

### 與 int 陣列的差別

| | char 陣列 | int 陣列 |
|---|---|---|
| 元素大小 | 1 byte | 4 bytes |
| 位址計算 | base + i | base + **i × 4**（需 `sll`） |
| 載入 / 存入 | `lbu` / `sb` | `lw` / `sw` |

> `strcpy` 是 leaf procedure；若 i 改放 `$t0`，就不用保存 `$s0`，可省 4 道指令。

## 重點整理

| 指令 / 概念 | 功能 | 注意事項 |
|---|---|---|
| ASCII | 128 字元 | 95 graphic + 33 control |
| Unicode | 32-bit 字元集 | UTF-8 / UTF-16 可變長度 |
| `lb` / `lh` | 載入 byte / halfword | sign extend |
| `lbu` / `lhu` | 載入 byte / halfword | zero extend；字元常用 |
| `sb` / `sh` | 存入最右 byte / halfword | |
| C 字串 | null-terminated | 迴圈以 `beq $t2, $zero` 結束 |
| char 位址 | base + i | 不用乘 4 |
