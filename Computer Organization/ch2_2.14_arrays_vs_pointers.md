# 2.14 陣列與指標（Arrays versus Pointers）

> Computer Organization and Design: The Hardware/Software Interface (6th Edition) — Chapter 2

---

## 本節涵蓋主題

| 主題 | 說明 |
|---|---|
| 陣列索引的成本 | index × 元素大小 + base |
| 指標 | 直接對應記憶體位址 |
| 範例 | `clear1`（陣列版）vs. `clear2`（指標版） |
| 比較 | 迴圈內指令數、strength reduction、induction variable elimination |

---

## 1. 陣列 vs. 指標

| | 陣列索引（Array indexing） | 指標（Pointers） |
|---|---|---|
| 位址計算 | index × 元素大小 + base address | 指標本身就是記憶體位址 |
| 每次迭代 | 要重新計算位址 | 直接加元素大小即可 |

---

## 2. 範例：清空陣列

### C 程式

```c
// 陣列版
clear1(int array[], int size) {
    int i;
    for (i = 0; i < size; i += 1)
        array[i] = 0;
}

// 指標版
clear2(int *array, int size) {
    int *p;
    for (p = &array[0]; p < &array[size]; p = p + 1)
        *p = 0;
}
```

### MIPS 程式（array 在 `$a0`、size 在 `$a1`）

**陣列版 `clear1`**：

```asm
       move $t0, $zero        # i = 0
loop1: sll  $t1, $t0, 2       # $t1 = i * 4
       add  $t2, $a0, $t1     # $t2 = &array[i]
       sw   $zero, 0($t2)     # array[i] = 0
       addi $t0, $t0, 1       # i = i + 1
       slt  $t3, $t0, $a1     # $t3 = (i < size)
       bne  $t3, $zero, loop1 # if (i < size) goto loop1
```

**指標版 `clear2`**：

```asm
       move $t0, $a0          # p = &array[0]
       sll  $t1, $a1, 2       # $t1 = size * 4
       add  $t2, $a0, $t1     # $t2 = &array[size]
loop2: sw   $zero, 0($t0)     # Memory[p] = 0
       addi $t0, $t0, 4       # p = p + 4
       slt  $t3, $t0, $t2     # $t3 = (p < &array[size])
       bne  $t3, $zero, loop2 # if (…) goto loop2
```

> `move` 是 pseudo-instruction，相當於 `add $t0, $zero, $a0`（使用 `$zero`）。

### 迴圈內指令數

| 版本 | 迴圈內指令 | 數量 |
|---|---|---|
| `clear1` | `sll`、`add`、`sw`、`addi`、`slt`、`bne` | **6** |
| `clear2` | `sw`、`addi`、`slt`、`bne` | **4** |

> 指標版把 `sll`、`add`（位址計算）**移出迴圈**；指標每次直接 +4（不是 +1）。

---

## 3. 比較與結論（Comparison of Array vs. Ptr）

| 觀念 | 說明 |
|---|---|
| **Strength reduction** | 乘法（× 4）被「降級」為較便宜的移位（`sll`） |
| 陣列版的成本 | 每次 i 遞增後都要重算位址，`sll` 必須在**迴圈內** |
| 指標版 | 只需遞增指標 |
| **Induction variable elimination** | 編譯器可自動把陣列版轉成指標版的效果 |

> 結論：現代編譯器能達到與手寫指標相同的效果，所以**寫成清楚、安全的程式（陣列）比較好**。

---

## 重點整理

| 概念 | 重點 |
|---|---|
| 陣列索引 | 每次迭代 index × 4 + base |
| 指標 | 每次 p += 4（元素大小） |
| 迴圈指令數 | 陣列 6 道 vs. 指標 4 道 |
| Strength reduction | 乘法 → 移位 |
| Induction variable elimination | 編譯器自動完成指標化 |
| 建議 | 優先寫清楚安全的程式碼，交給編譯器最佳化 |
