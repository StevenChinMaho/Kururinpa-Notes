## 1. 計算機的五大元件（Components of a Computer）

> 所有類型的計算機（desktop、server、embedded）都由**相同的元件**組成。

| 元件 | 功能 |
|---|---|
| Input | 將資料送入計算機 |
| Output | 將結果送出計算機 |
| Memory | 存放程式與資料 |
| Datapath（數據通道） | 對資料執行運算 |
| Control（控制） | 依指令指揮 datapath、memory、I/O 的動作順序 |

> **Datapath + Control = Processor（處理器）**

### I/O 裝置分類

| 類型 | 例子 |
|---|---|
| 使用者介面裝置（user-interface devices） | 顯示器、鍵盤、滑鼠 |
| 儲存裝置（storage devices） | 硬碟、CD/DVD、flash |
| 網路介面（network adapters） | 與其他電腦通訊 |

## 3. 處理器內部（Inside the Processor）

### 3.1 處理器的組成

| 部分 | 功能 |
|---|---|
| Datapath | 對資料執行運算（performs operations on data） |
| Control | 安排 datapath、memory 等的動作順序（sequences） |
| Cache memory | 小而快的 **SRAM**，提供資料的即時存取 |

### 3.2 晶片實例

| 晶片 | 組成 |
|---|---|
| Apple A5 | 2 個 ARM core、Processor Data Path、I/O、DDR SDRAM interface、Video DAC、Audio、WiFi 等 |
| Apple A12 | 2 大核（Vortex）+ 4 小核（Tempest）+ 4 核 GPU，另有 NPU、System Cache、L2 Cache |

> 觀察：現代 SoC 中，CPU core 只佔晶片面積一小部分，GPU、NPU、Cache 佔了大量面積，呼應 1.1 節「領域專用加速器」的趨勢。

## 4. 抽象化（Abstractions）

> Abstraction helps us deal with complexity —— 隱藏下層細節。

| 名詞 | 定義 |
|---|---|
| **ISA**（Instruction Set Architecture，指令集架構） | **硬體／軟體介面**；包含程式設計師需要知道的一切，才能寫出正確的機器語言程式 |
| **ABI**（Application Binary Interface） | **ISA + 系統軟體介面**（例如 OS 的系統呼叫）；決定 binary 程式在不同電腦間的可攜性 |
| **Implementation（實作）** | 遵循介面之下的實際硬體細節 |

> 同一個 ISA 可以有多種 implementation（例如 Intel 與 AMD 都實作 x86），軟體不需修改即可在兩者上執行。

## 重點整理

| 概念 | 重點 |
|---|---|
| 五大元件 | Input、Output、Memory、Datapath、Control |
| Processor | Datapath + Control |
| Cache | 處理器內的小型快速 SRAM |
| ISA | 硬體／軟體介面 |
| ABI | ISA + 系統軟體介面 |
| Implementation | 介面之下的硬體細節；同一 ISA 可有多種實作 |
