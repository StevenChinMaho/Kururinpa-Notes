## 1. 32 位元常數（32-bit Constants）

- 大多數常數很小，16-bit 立即值就夠用。
- 偶爾需要 32-bit 常數時，使用 **`lui`（load upper immediate）**：
  - 把 16-bit 常數複製到 rt 的**左 16 bits**
  - 把 rt 的**右 16 bits 清為 0**

### 範例：載入 4,000,000（= `0x003D0900`）

4,000,000 = 61 × 2¹⁶ + 2304

```asm
lui $s0, 61           # $s0 = 0000 0000 0011 1101 | 0000 0000 0000 0000
ori $s0, $s0, 2304    # $s0 = 0000 0000 0011 1101 | 0000 1001 0000 0000
```

> ⚠ 投影片（與教科書原圖）把上半部寫成 `0000 0000 0111 1101`，那是 125；61 的正確位元是 **`0011 1101`**。

> 下半部用 `ori` 而不是 `addi`：`addi` 會對立即值做 sign extension，若下半部 bit 15 為 1 會弄壞上半部；`ori` 是 zero extension。

## 2. 分支定址（Branch Addressing）

分支指令包含：opcode、兩個暫存器、目標位址。大多數分支目標都在附近（往前或往後）。

使用 I-format：

| op | rs | rt | constant or address |
|---|---|---|---|
| 6 bits | 5 bits | 5 bits | 16 bits |

**PC-relative addressing（相對定址）**：

$$
\text{Target address} = \text{PC} + \text{offset} \times 4
$$

| 重點 | 說明 |
|---|---|
| PC 的值 | 執行時 **PC 已經加 4**（指向分支的下一道指令） |
| offset 單位 | **word**（指令數）；乘 4 換成 byte 位址 |
| 意義 | 「從目前分支的下一道指令起，往前／往後跳第 ± 幾道指令」 |
| 範圍 | ±2¹⁵ 道指令 |

---

## 3. 跳躍定址（Jump Addressing）

`j`、`jal` 的目標可能在 text segment 任何地方 → 指令中盡量放入完整位址。

**J-format**：

| op | address |
|---|---|
| 6 bits | 26 bits |

**(Pseudo)Direct jump addressing（絕對定址）**：

$$
\text{Target address} = \text{PC}_{31\ldots28} : (\text{address} \times 4)
$$

| 位元 | 來源 |
|---|---|
| 31–28（4 bits） | 目前 PC 的高 4 位 |
| 27–2（26 bits） | 指令中的 address |
| 1–0（2 bits） | 00（address × 4） |

> 意義：「跳到程式中的第幾道指令」（word addressing）。

### Jump 範圍

PC 高 4 bits 不變、最低 2 bits 恆為 00，只有中間 26 bits 能改變 →
跳躍範圍只在同一個 **2²⁸ = 256 MB** 區塊內。

| PC[31:28] | 可跳範圍 |
|---|---|
| 0000 | `0x0000 0000` ~ `0x0FFF FFFC` |
| 0011 | `0x3000 0000` ~ `0x3FFF FFFC` |

## 4. 目標位址範例（Target Addressing Example）

2.7 的迴圈，假設 `Loop` 位於位址 80000：

| 指令 | 位址 | op | rs | rt | rd | shamt | funct / imm |
|---|---|---|---|---|---|---|---|
| `Loop: sll $t1, $s3, 2` | 80000 | 0 | 0 | 19 | 9 | 2 | 0 |
| `add $t1, $t1, $s6` | 80004 | 0 | 9 | 22 | 9 | 0 | 32 |
| `lw $t0, 0($t1)` | 80008 | 35 | 9 | 8 | | | 0 |
| `bne $t0, $s5, Exit` | 80012 | 5 | 8 | 21 | | | **2** |
| `addi $s3, $s3, 1` | 80016 | 8 | 19 | 19 | | | 1 |
| `j Loop` | 80020 | 2 | | | | | **20000** |
| `Exit: …` | 80024 | | | | | | |

> ⚠ 投影片 `sll` 那列的 shamt 寫成 4；`sll $t1, $s3, 2` 的 shamt 應為 **2**。

### 計算 bne 的 offset

執行 `bne` 時 PC = 80012 + 4 = **80016**：

$$
80024 = 80016 + x \times 4 \;\Rightarrow\; x = 2
$$

### 計算 j 的 address

$$
\text{address} = 80000 / 4 = 20000
$$

> 兩者都用 **word** 為單位：branch 存「相對距離 ÷ 4」，jump 存「絕對位址 ÷ 4」。

## 5. 遠距分支（Branching Far Away）

分支目標太遠、16-bit offset 放不下時，**assembler 會改寫程式碼**：

```asm
beq $s0, $s1, L1      # 原本：L1 太遠
```

↓ 改寫為

```asm
      bne $s0, $s1, L2  # 條件反轉，16-bit offset 只需跳過下一道
      j   L1            # 用 26-bit 的 j 跳到遠方
L2:   …
```

## 6. 定址模式總整理（Addressing Mode Summary）

| # | 模式 | 運算元位置 | 例子 |
|---|---|---|---|
| 1 | **Immediate addressing** | 常數就在指令中 | `addi $s0, $s1, 4` |
| 2 | **Register addressing** | 運算元在暫存器 | `add $t0, $s1, $s2` |
| 3 | **Base addressing** | 記憶體位址 = 暫存器 + 指令中的常數 | `lw $t0, 32($s3)` |
| 4 | **PC-relative addressing** | 位址 = PC + 常數 × 4 | `beq`、`bne` |
| 5 | **Pseudodirect addressing** | 位址 = PC 高 4 bits 串接 26-bit × 4 | `j`、`jal` |

## 重點整理

| 概念 | 公式 / 方法 | 注意事項 |
|---|---|---|
| 32-bit 常數 | `lui` 上半 + `ori` 下半 | 下半用 `ori`（zero extend） |
| Branch | PC + 4 + offset × 4 | offset 以 word 計；PC 已加 4 |
| Jump | PC[31:28] : address × 4 | 範圍 256 MB 區塊 |
| J-format | op 6 / address 26 | `j`、`jal` |
| 遠距分支 | `bne` 反轉 + `j` | assembler 自動處理 |
| 定址模式 | 5 種 | Immediate、Register、Base、PC-relative、Pseudodirect |

### 三種格式總覽

| 格式 | 欄位 | 指令 |
|---|---|---|
| R | op 6 / rs 5 / rt 5 / rd 5 / shamt 5 / funct 6 | `add`、`sub`、`and`、`or`、`nor`、`slt`、`sll`、`srl`、`jr` |
| I | op 6 / rs 5 / rt 5 / imm 16 | `addi`、`andi`、`ori`、`slti`、`lw`、`sw`、`lb`、`sb`、`lui`、`beq`、`bne` |
| J | op 6 / address 26 | `j`、`jal` |
