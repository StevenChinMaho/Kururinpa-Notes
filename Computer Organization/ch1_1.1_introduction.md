## 1. 計算機革命（The Computer Revolution）

- 計算機技術的進步，近年主要由**領域專用加速器（domain-specific accelerators）**推動（如 GPU、NPU）。
- 技術進步讓過去不可行的應用變得可行：車用電腦、手機、人類基因組計畫、World Wide Web、搜尋引擎。
- 結論：**計算機無所不在（Computers are pervasive）**。

---

## 2. 摩爾定律（Moore's Law）

1965 年由 Intel 共同創辦人 Gordon Moore 觀察提出：

> 積體電路上的電晶體數量約**每兩年倍增**。

投影片圖表（1971–2011）：從 Intel 4004 的約 2,300 顆電晶體，成長到 16-Core SPARC T3、10-Core Xeon Westmere-EX 的約 26 億顆，在對數座標上接近一條直線。

---

## 3. 計算機分類（Classes of Computers）

| 類別 | 特性 | 設計重點 |
|---|---|---|
| Personal computers | 通用（general purpose）、可執行各式軟體 | **cost/performance tradeoff** |
| Server computers | 以網路為基礎（network based）；規模從小型伺服器到整棟建築 | **high capacity, performance, reliability** |
| Supercomputers | 高階科學與工程計算 | 能力最高，但只佔整體市場一小部分 |
| Embedded computers | 隱藏在系統內作為元件（如車用、家電） | **stringent power / performance / cost constraints** |

> Embedded computer 是數量最多的一類，只是使用者通常感覺不到它的存在。

---

## 4. PostPC 時代（The PostPC Era）

### 4.1 個人行動裝置（Personal Mobile Device, PMD）

- 電池供電（battery operated）
- 連接網際網路
- 價格約數百美元
- 例：智慧型手機、平板、電子眼鏡

### 4.2 雲端運算（Cloud Computing）

| 名詞 | 說明 |
|---|---|
| Warehouse Scale Computers（WSC） | 倉儲規模的大型電腦叢集，即資料中心 |
| Software as a Service（SaaS） | 軟體以服務形式透過網路提供 |
| 分工模式 | 一部分軟體在 PMD 上執行，一部分在 Cloud 執行 |
| 代表業者 | Amazon、Google |
